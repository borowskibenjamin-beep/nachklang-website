# Nachklang Creator Pipeline

## Legende

| Status | Bedeutung |
|---|---|
| Neu | Creator wurde identifiziert, noch kein Kontakt |
| Shortlist | Creator auf Shortlist für mögliche Kooperation |
| Kontaktiert | Erstkontakt hergestellt, auf Rückmeldung wartend |
| Antwort | Creator hat geantwortet, Details werden geklärt |
| Partner | Kooperationsvertrag/Vereinbarung abgeschlossen |
| Abgelehnt | Creator hat abgelehnt oder ist nicht interessiert |
